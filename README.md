# DMZ Squad Guide

A mobile-friendly companion with four mission walkthroughs, maps, gameplay screenshots, and checklists.

**Open and share:** https://q0de.github.io/dmz-squad-guide/#shopping-hacks

## Hosting

GitHub Pages serves the `docs/` directory on the `main` branch. The website needs no account or sign-in. There is no ChatGPT runtime or hosting dependency. Checklist progress stays in each visitor’s browser.

## Editing

Edit `docs/index.html`, `docs/styles.css`, `docs/app.js`, and `docs/visual-data.js`. Assets are in `docs/assets/`. After changes, run `node prepare-offline.mjs` to rebuild the downloadable single-file guide, then push to `main`.
